# PowerSync icon

The approved amber aragonite and teal sync-arrow artwork is the product icon for
`dev.aragonite.powersync.client`. The diagnostic probe keeps its existing identity.

`powersync-aragonite-sync-concept-v1.png` is the original transparent artwork.
Its matching prompt is retained beside it. The unchanged artwork is copied into
the product's `drawable-nodpi` resources. The adaptive icon uses a white background
and a one-sixth inset to keep the full arrows inside launcher masks; themed icons
use its alpha silhouette. Legacy launcher PNGs are flattened onto white at
48, 72, 96, 144 and 192 pixels.

Release 0.1.1 (version code 2) adds this icon and preserves the existing signing
identity, application ID and private transition state.
