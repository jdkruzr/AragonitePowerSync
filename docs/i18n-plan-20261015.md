# Internationalization (2026-10-15)

Owner-approved plan, shared with Alexandria Server (its `docs/i18n-plan-20261015.md`
covers the server side). First target language: **Spanish (`es`)**. The first Spanish
catalog was drafted by Claude; it must stay easy for people to correct and extend.

## PowerSync (done in 0.2.0)

- All user-facing text lives in `client/src/main/res/values/strings.xml` (English
  source) and `values-<locale>/strings.xml` (translations). 183 translatable
  entries: the screen, dialogs, two plurals, and 124 error messages.
- Errors that reach the status line are `UserError` (a string resource ID plus
  format arguments), resolved in the device language by `MainActivity.safe()`.
  The exception message itself is a language-free key, so logs and tests don't
  depend on wording. Journal notes in private state stay English (never shown).
- Native status codes are shown as words (on/off, signed in/out, settled setup
  phases). Transient phases still show their code; they only appear mid-transition.
- `ServerClient` sends `Accept-Language` so server-provided text (the recovery
  status summary) can follow the device language once Alexandria is localized.
- Per-app language: `androidResources.generateLocaleConfig` plus
  `res/resources.properties` (`unqualifiedResLocale=en`). Android lists PowerSync's
  languages under App languages; `adb shell cmd locale set-app-locales
  dev.aragonite.powersync.client --locales es` also works (empty list resets).
- Lint fails the build on `HardcodedText`, `SetTextI18n`, `MissingTranslation`,
  `StringFormatInvalid`, `StringFormatMatches` and `MissingQuantity`, so new text
  can't bypass the catalog and every language must cover every string.
- Verified on the Palma with PowerSync set to Spanish: all screen text and status
  words render, buttons fit. Language reset afterwards.

## Conventions (both apps)

- Product and feature names are never translated: PowerSync, Alexandria, BOOX,
  ksync, Audio Note Minutes, Template Hub. BOOX's own app names follow the
  device's translation (Notes → Notas, Settings → Ajustes).
- Spanish uses informal *tú*, as Android does.
- Title Case is an English rule; other languages use their own heading style
  (Spanish: sentence case).
- Formats stay tool-native (Android `strings.xml`, go-i18n JSON) so Weblate or
  Crowdin can import them without conversion. Self-hosted Weblate is the
  intended workflow later.

See [translating.md](translating.md) for how to correct or add a language.
